# Security Context

IMPORTANT NOTE: NexaPack Executive Packer inherits the security context of any files it handles.

This means that packing, unpacking, or even testing or listing a file requires
the same security considerations as actually executing the file.

Use NexaPack Executive Packer on trusted files only!

## Supported Versions

| Version   | Supported          |
| --------- | ------------------ |
| git HEAD  | :white_check_mark: |
| any other | :x:                |
